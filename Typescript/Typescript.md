
Typescript  
 =========
      --> Free and open source
      --> Superset of javascript developed by microsoft
      --> Typed language
      --> Typescript is compiled
    

 Typescript Architecture:
 =======================
Typescript code ---> Typescript Compiler ---> Javascript  code ---> javascript runtime
 .ts file       --->   tsc               --->  .js file         --->  node.js 

tsc --> typescript compiler
