Creating the Array
=================
    
   Array can be created in 2 ways
     
     1. Array literal
     2. Array constructor

 Array literal
 =============
  
  let arrayname=[value1,value2........]

  Array constructor
  ================

  let arrayname=new Array(value1,value2,value3)
